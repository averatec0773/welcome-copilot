# docs/

Design documents for this project's submission package.

- [`sketch.md`](sketch.md) — the one-page answer to the practical task: what
  I'd use, what could go wrong, how I'd know it silently stopped. Doubles as
  the text pasted into the application form.
- [`design.md`](design.md) — the full set of design decisions and their
  trade-offs, including the PII-vs-PHI boundary and what was consciously
  left out.
- [`tracker-v2.md`](tracker-v2.md) — what breaks in the shared-spreadsheet
  tracker at scale, and the staged migration path off it.
- [`RUNBOOK.md`](RUNBOOK.md) — the guide a non-technical operator needs to
  run all of this: one scenario at a time, no code.
